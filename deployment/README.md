# Deployment boundary

The YAML file in this directory is intentionally outside `.github/workflows`
and contains unresolved tokens. It cannot trigger or acquire metadata.

The capture-orchestration core, production HTTPS adapter, cryptographic
initiation binding, and immutable action/container pins are frozen but inert.
Materialization remains fail-closed until a later authorization supplies the
single scheduled UTC event, its RFC-3161 precommit, the derivation-verified
request-plan identity, and the final V2.3.7 deployment manifest.
