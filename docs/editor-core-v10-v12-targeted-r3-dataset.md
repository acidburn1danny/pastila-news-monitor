# Editor Core V10 V1.2 targeted R3 dataset

R3 is an epistemic-calibration-only continuation pack parented by the selected
R2 step-9 adapter. It contains 24 new training rows, 24 deterministic replay
anchors, and a separate 12-case independent holdout.

The new rows teach three independently material components: attribution of the
allegation or preliminary finding, the subject's denial or contest, and the
absence of a final determination. Replay is balanced across retained V10, R1,
and R2 training sources. The six R2 diagnostic holdout cases identify the
failure cluster but neither their requests nor targets are training inputs.

The R3 holdout uses new entities, quantities, locations, wording, identities,
authority spans, and targets. Training remains unauthorized until dataset,
tokenizer, provenance, replay, and anti-contamination closure all pass and a
separate launcher/training authorization is granted. This pack performs no
promotion, release, adjudication, model load, training, or optimizer activity.
