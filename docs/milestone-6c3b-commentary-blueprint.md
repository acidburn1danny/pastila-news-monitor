# Milestone 6C.3B — deterministic commentary blueprint

The private commentary stage consumes the frozen Scout input, selection profile,
episode context, optimized flow, and generic editorial blueprint. It returns the
unchanged validated public Editor output plus a controlled commentary plan and
decision trace.

The stage creates no publishable language. Every choice is an enum, identifier,
safe public field reference, or provenance reference. Sensitivity is accepted only
from explicit event extension metadata; missing or invalid metadata uses the safest
deterministic `ordinary` fallback and is recorded in the trace. Principal actors are
likewise referenced only when explicitly supplied in public extensions.

Replaceable rules independently assign sensitivity, targets, irony, audience
strategy, relevance, comparisons, empathy, beats, punchline intent, transitions,
evidence discipline, and episode consistency. Cross-model validation preserves the
optimized order, checks provenance, keeps backup/excluded stories out of main
segments, enforces transition cardinality, and applies sensitive-story safeguards.
