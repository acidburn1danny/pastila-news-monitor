# Architecture

The package separates immutable models, canonical identity, pure planning, structured validation, readiness, rendering, and fingerprinting. Its canonical identity is `pastila-acida-editorial-composition-engine` version `1.0.0`.

Upstream systems remain immutable and are represented through identity/version/fingerprint/readiness references. Composition cannot alter selection, Story Architecture, Persona, Philosophy, Voice, Audience, Spoken Communication, Romanian Conversation, or Editorial Language Learning.
