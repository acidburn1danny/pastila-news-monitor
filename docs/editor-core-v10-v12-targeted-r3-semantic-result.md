# Editor Core V10 V1.2 targeted R3 semantic result

The published independent evaluation rejects R3 step-6 as a development
parent. R2 step-9 remains the selected development parent. Both candidates
produced structurally valid responses for all 12 frozen cases, but R2 preserved
the required epistemic boundary in 12/12 cases while R3 preserved it in 9/12.

R3 introduced three regressions in the attribution/denial/finality partition
and produced no semantic improvement. In those cases it removed the suspicion
or modal framing and stated the alleged reporting error too directly. The
frozen R3 holdout remains evaluation evidence and none of its targets may be
used for training.

This is a development-only rejection. It performs no promotion, release,
training, optimizer activity, adjudication, or mutation of runtime evidence.
