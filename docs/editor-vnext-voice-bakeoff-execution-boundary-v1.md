# VNext VOICE Three-Candidate Blind Bake-off Execution Boundary v1

Fixture-only boundary for 24 development cases, three frozen candidates and three common seeds (216 planned slots). Runtime slots contain blind labels only; the answer key is a separate, runtime-forbidden artifact.

The boundary freezes candidate revisions, tokenizer bytes, decoding, factual invariants, output schema and terminal rules. It authorizes no model load, quantization, generation, scoring, unsealing, selection, training or promotion.
