# Editor Core V10 V1.2 targeted R3 failure-mining plan

R3 is restricted to the six unresolved `EPISTEMIC_CALIBRATION` diagnostics in
the frozen R2 holdout. Those cases remain evaluation evidence and their targets
must never become training examples.

The demonstrated failure is omission of one or more independently material
epistemic components: attribution of the allegation, the subject's denial or
contest, and the absence of a final determination. R3 must teach preservation
of all supplied positions while retaining allegation language and procedural
uncertainty.

The smallest proposed round is:

- 24 new targeted training rows, four new disjoint variants for each observed
  diagnostic pattern;
- 24 replay anchors drawn deterministically from retained V10, R1, and R2
  training corpora, without holdout material;
- a new independent 12-case holdout, split evenly between persistent omission
  patterns and the two R2 regression patterns;
- one epoch, micro-batch 1, gradient accumulation 8, producing six optimizer
  steps if and only if separately authorized after dataset closure.

New entities, quantities, locations, wording, request identities, authority
spans, and targets must be disjoint from every retained train/dev/shadow/R1/R2/
R4 corpus. The build must run exact and lexical anti-contamination checks. R3
must retain transition and unsupported-claim behavior through replay and a
regression evaluation; it must not use R4 evidence or resume adjudication.

Closure requires dataset, tokenizer, provenance, replay, and anti-contamination
`PASS + 0 BLOCKERS` before any launcher or training work. This plan selects R2
step-9 only as a development parent. It performs no training, release,
promotion, qualification, certification, or adjudication.
