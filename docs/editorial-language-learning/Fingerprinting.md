# Semantic Fingerprinting

## Responsibilities and contract

Every artifact exposes `semantic_sha256`; helpers hash canonical UTF-8 JSON with sorted keys and normalized independent collections. Operations, evidence chronology, principles, and lifecycle transitions preserve order. Self-fingerprint fields and provenance timestamps are excluded from their own identity.

## Limitations and guarantees

Equivalent meaning hashes identically and semantic changes alter the digest. Hashing performs no mutation and includes no secrets, runtime identifiers, or generated language.
