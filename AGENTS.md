# AGENTS

This repository is a Python 3.14 project using a `src` layout.

- Keep changes focused and prefer simple, maintainable implementations.
- Put application code in `src/pastila_scout/`.
- Put tests in `tests/` and run them with `pytest`.
- Add runtime dependencies to `project.dependencies` in `pyproject.toml`.
- Add development-only dependencies to the `dev` optional dependency group.
- Document significant design decisions and user-facing changes.
- Do not commit virtual environments, caches, generated data, or secrets.
